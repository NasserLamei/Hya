# هي

تطبيق موبايل للبنات، بيفتح بواجهة مختلفة حسب المرحلة: تخطيط للحمل، أو حمل، أو بعد الولادة. الشغل على الماك، والتشغيل على iOS وAndroid فقط.

التطبيق معرفة ودعم، مش بديل عن الطبيب أو الصيدلي.

## التشغيل على الآيفون

من مجلد المشروع:

```bash
flutter devices
flutter run
```

لو فيه أكتر من جهاز، اختاري محاكي الآيفون:

```bash
flutter run -d apple_ios_simulator
```

Xcode موجود على الجهاز، فبناء iOS بيشتغل من هنا. أندرويد محتاج Android Studio وAndroid SDK؛ مجلد `android/` جاهز، والبناء عليه لما الأدوات تتنزّل.

## ربط Supabase

1. اعملي مشروع على [supabase.com](https://supabase.com).
2. من SQL Editor، شغّلي `supabase/schema.sql`.
3. من Authentication، فعّلي الإيميل. للتطوير السريع، اقفلي Confirm email عشان الدخول يحصل من غير رسالة.
4. انسخي Project URL و anon key في ملف `env.json` جنب `pubspec.yaml` (النسخة الفاضية في `env.example.json`). الملف ده متتجاهل من جيت.

```json
{
  "SUPABASE_URL": "https://YOUR_PROJECT.supabase.co",
  "SUPABASE_ANON_KEY": "YOUR_ANON_KEY"
}
```

5. شغّلي:

```bash
flutter run --dart-define-from-file=env.json
```

من غير الملف، التطبيق يشتغل بالكامل على الموبايل. الحساب من الإعدادات بيحفظ البروفايل واليوميات والكبسولة وسجل البيبي.

## اللي موجود

- شاشة بداية بتسأل: بتخططي، ولا حامل، ولا بعد الولادة، والواجهة بتتغير.
- تخطيط: يوم الدورة، نافذة خصوبة تقديرية، استعداد قبل الحمل.
- حمل: أسبوع من ٤٠، رسالة، أعراض، عدّاد حركة، رسالة للي جنبها، حقيبة المستشفى.
- بعد الولادة: عمر البيبي، رضاعة يمين/شمال، حفاض ونوم، تعافي، تذكير تطعيمات مصر.
- درع: دليل أدوية وأكل وأعشاب بنظام أخضر/أصفر/أحمر، وشرح مصطلحات تقرير السونار من غير ما التطبيق يقرأ الأشعة أو يقول إن الرقم طبيعي.
- مصفاة خرافات من مكتبة معروفة، وبتوقف الطمأنة لو الكلام فيه نزيف أو قلة حركة أو ضيق نفس.
- كبسولة رسائل بموعد فتح في المستقبل.

## اللي متعمّد ما يتعملش

تفسير صورة السونار بالذكاء الاصطناعي، أو طمأنة طبية مولّدة، مش جزء من النسخة دي. الغلط فيها يضر. المصطلحات تتشرح، والحكم يفضل عند الطبيب.
